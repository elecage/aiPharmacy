# 앱인벤터 개발 자동화 도우미

이 폴더는 기존 Markdown 문서를 바탕으로 앱인벤터 개발 단계를 안내하는 React/Vite MVP이다.

## 실행

```bash
npm install
npm run dev
```

## 1차 기능

- 문서 목록 표시
- 개발 단계 대시보드
- 선택 단계 상세 안내
- 앱인벤터 컴포넌트 목록
- 블록 구현 순서
- Android/iPhone/Web API/발표 체크리스트
- 안전 문구 상시 표시

## 안전 원칙

```text
AI 분석 결과는 참고용입니다.
복용 전 반드시 약사 또는 의사에게 확인하세요.
```
